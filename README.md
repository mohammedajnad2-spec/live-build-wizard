Pro Prompt لـ Lovable:

​"قم بتجهيز الواجهات والتفاعلات كاملة للتطبيق مع التأكد من إظهار المعاينة الحية (Live Preview) بشكل صحيح.

​عند تجهيز ملفات المشروع للتصدير (Export/ZIP)، يرجى التأكد من التالي:

​تضمين إعدادات Capacitor كاملة في ملف capacitor.config.ts.

​إضافة برمجيات البناء الأسطر البرمجية المساعدة في package.json لإضافة منصة أندرويد تلقائياً (مثل npx cap add android و npx cap sync).

​التأكد من أن جميع المسارات (Assets & Routes) تعمل بشكل نسبي وتدعم الـ Hybrid Mobile Build بدون أخطاء مسارات عند تحويلها إلى Android Studio."

```sh
git clone <this-repository-url>
```
